# Dylphiiee — Portfolio

Website portofolio personal untuk Dylphiiee, dibuat dengan Next.js, TypeScript, Tailwind CSS, dan Motion.

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Mengganti konten

Semua isi ada di folder `data/`:

- `data/profile.ts`: nama, teks hero, tentang, kontak, dan sosial media. Username GitHub juga diatur di sini (`githubUsername`).
- `data/projects.ts`: daftar proyek.
- `data/stack.ts`: teknologi yang ditampilkan.
- `data/services.ts`: layanan.

Komponen UI ada di `components/`.

## Build

```bash
npm run build
npm start
```
